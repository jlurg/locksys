# locksys_protocol

Pure Dart implementation of the LockSys APP <-> CGW protocol 1.0 (LS-SAIC-001 §8).

| File | Content |
|---|---|
| `lib/src/gen/` | Generated by `tools/codegen/regen.py`: protobuf messages (protoc_plugin 25.1.0, protobuf 6.1.0), `LsParams`, `LsNotices`/DTC constants. Never edited by hand. |
| `lib/src/hkdf.dart` | HKDF-SHA256 (RFC 5869) |
| `lib/src/session_crypto.dart` | Proofs, K_sess derivation, frame tags |
| `lib/src/frame_codec.dart` | `Frame` encoding, receive-path checks, `SessionChannel` counters |
| `lib/src/close_codes.dart` | Close codes, reconnect policy and backoff |
| `lib/src/ct_equal.dart` | Constant-time comparison |

Tests use the shared vectors in `interfaces/vectors/` (`app_session_v1.json`, `crypto_kat.json`).

```sh
fvm dart test
fvm dart run coverage:test_with_coverage --branch-coverage
```
