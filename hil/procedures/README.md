# Manual procedure bodies

The index, scope and acceptance criteria of the manual and semi-automatic procedures are in LS-VER-002 (`docs/07_verification/procedures/README.md`). This directory holds the executable procedure bodies `TST-MAN-SYS-nnn.md` with their record templates.

| Milestone | Procedures |
|---|---|
| Bench build | TST-MAN-SYS-016 |
| M1 | TST-MAN-SYS-001, -002, -003, -009 |
| M2 | TST-MAN-SYS-004, -005, -006, -007, -008, -010, -011, -012, -015 |
| M3 | TST-MAN-SYS-013 |
| M4 | TST-MAN-SYS-017 |
| M6 | TST-MAN-SYS-014 |

Each body is written from `TEMPLATE.md` before the milestone that first needs it. Completed records go to `hil/qualification/` or to the release evidence pack. Every procedure applies the bench safety rules of LS-HIL-001 section 12.
